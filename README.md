# 📟 Tabuada Retrô

Projeto desenvolvido em Python inspirado em um brinquedo educativo da infância.

---

## 📖 Sobre

O objetivo deste projeto é recriar a experiência de um brinquedo educativo retrô utilizando Python, evoluindo o projeto em diferentes versões até uma interface gráfica completa.

---

## 🚀 Funcionalidades

- ✅ Modo Retrô
- ✅ Modo Treino
- 🚧 Modo Desafio
- 🚧 Estatísticas
- 🚧 Interface Gráfica (Tkinter)

---

## 🛠 Tecnologias

- GitHub
